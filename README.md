# Character Counter

Web application that counts characters in real time as you type.

## Technologies Used

- **HTML5** 
- **CSS3** 
- **JavaScript** 

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/ivayylkaa/character-counter.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
